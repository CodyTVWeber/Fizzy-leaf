# Fizzy Leaf

Shopify Hydrogen storefront for Fizzy Leaf sparkling hibiscus tea (Middle TN). Live on Oxygen at [fizzyleaf.com](https://fizzyleaf.com).

## Requirements

- Node.js 22.x or 24.x

## Local development

```bash
npm install
npm run dev
```

Or use the helper script (creates `.env` from `.env.example` if missing):

```bash
./scripts/run-local.sh
```

Dev server: http://localhost:3000/

## Build & lint

```bash
npm run build
npm run lint
```
